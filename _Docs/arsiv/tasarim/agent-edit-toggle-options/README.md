# Ajan ayarları seçim kontrolü — tarihsel tasarım

Bu üçlü, ajan ayarlarında pill biçiminde seçim kontrollerini karşılaştıran eski
tasarım taslağıdır; uygulamanın aktif arayüz kaynağı değildir.

- `agent-edit-toggle-options.png`: tasarımı doğrudan incelemek için önizleme.
- `agent-edit-toggle-options.op`: düzenlenebilir tasarım belgesi.
- `agent-edit-toggle-options.js`: aynı sahneyi tasarım ortamının `I(...)` ekleme
  API'siyle oluşturan kaynak. Node.js veya tarayıcıda bağımsız çalışmaz; ilgili
  tasarım ortamında çalıştırılır.

Geçmiş seçimleri karşılaştırmak gerektiğinde PNG açılır; tasarım yeniden ele
alınacaksa `.op` belge veya özgün ortamda JS kaynak kullanılır. Üç dosya arşive
taşınırken içerikleri değiştirilmedi.

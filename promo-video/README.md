# TionHarness promo video

Remotion project that renders a 39 s promo in three formats from one timeline:
`Horizontal` (1920x1080), `Vertical` (1080x1920), `Square` (1080x1080).

```bash
npm install
npm run music     # synthesise public/music.wav (original, license-free)
npm run studio    # live preview
npm run render    # music + all three mp4s into out/
```

The soundtrack is generated by `scripts/make-music.mjs` at 120 BPM; one beat is
exactly 15 frames at 30 fps, so every scene in `src/theme.ts` (`SCENES`, in beats)
cuts on a kick. Change scene lengths there and in the song map together.

Scenes: intro logo -> Agents -> Delegate (coordinator/workers) -> Flows ->
Automate (board triggers) -> Isolated (workspaces) -> Connect (tools & MCP) ->
Control (permissions) -> Any model (providers) -> 1 binary / 0 databases /
0 API keys -> themes -> outro.

## Flow videos (vertical, 1080x1920)

Three short English videos about the evolving per-agent flows (`_Docs/93-EVRILEN-AKISLAR.md`),
each with its own synthesised soundtrack (`scripts/make-flow-music.mjs`, built on
`scripts/lib/synth.mjs`). Every song's beat is a whole number of frames, so scene
lists (in beats) in `src/flows/*.tsx` cut on the beat.

| Composition | Topic | Music | Length |
|---|---|---|---|
| `FlowsOverview` | one main flow per agent, node types, safe loops, live steps, Flows screen | `neon.wav` synthwave, 120 BPM (15 f/beat) | 36 s |
| `FlowsEvolution` | versions, `edit_flow`, Flow Observer, budget + revert | `dusty.wav` lo-fi, 90 BPM (20 f/beat) | 37.3 s |
| `FlowsJev` | criteria gate, run grading, proposal gate, trigger node, flow-kind automations | `signal.wav` cinematic, 100 BPM (18 f/beat) | 38.4 s |

```bash
npm run render:flows                                   # music + all three mp4s into out/flows/ (earlier Turkish cut: out/flows/tr/)
node scripts/flow-stills.mjs FlowsJev 100,300,500       # review stills into out/stills/FlowsJev/
```

Shared pieces (node cards, edges, tokens, captions, outro) live in `src/flows/kit.tsx`;
`src/flows/FlowVideo.tsx` sequences the scenes over the soundtrack.

Installation is a download and a run: there is no database to provision, no
container to build and no service account to create. This page is a placeholder
that describes the shape of the real instructions.

## Requirements

A 64-bit Windows, Linux or macOS machine, plus credentials for at least one model
provider.

## Running the binary

Unpack the archive and start the executable. It opens a local HTTP port and
prints the address to the console.

```bash
./tionharness
```

## Verifying the install

Open the printed address in a browser. The workspace picker means the runtime
came up correctly.
